## Sobre este repositório

Este repositório hospeda a **página de entrada** do portfólio profissional de Flávio Mattos, publicada via **GitHub Pages** em [`oflaviomattos.github.io`](https://oflaviomattos.github.io).

A página funciona como um portal intermediário — apresenta os principais links profissionais e redireciona automaticamente para o site principal [`flaviomattos.com`](https://flaviomattos.com) após 8 segundos.

A página foi desenvolvida com identidade visual consistente com o site principal:

| Elemento | Detalhe |
